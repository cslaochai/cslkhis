# 实习医生与试用期医师兼容方案

> 状态：规划稿，未排期。MVP 阶段医生账号全部为执业医师，本期不实现。
> 触发条件：接入规培基地 / 教学医院 / 有真实下级医师坐诊时启动。

---

## 1. 法规前提（红线，不是设计选择）

| 角色 | 能否独立坐诊 | 病历效力 | 处方效力 |
|---|---|---|---|
| 执业医师（已注册、有处方权） | 能 | 自己写自己签即生效 | 自己签即生效 |
| 试用期医师（已考证未注册满） | 能独立接诊 | **必须当天上级医生审签**才生效 | **必须经有处方权医师审核签名**才生效 |
| 实习医生（医学生，未考证） | **不能独立出诊**，只能在带教老师视线内抄写 | **带教老师必须审签双签**，否则非法行医 | 不能独立开方 |
| 进修医生 | 看医院授权 | 同试用期 | 同试用期 |

依据：
- 《执业医师法》第十四条：未经医师注册取得执业证书，不得从事医师执业活动
- 《病历书写基本规范》第八条：实习/试用期医务人员书写的病历，应当经过本医疗机构合法执业的医务人员审阅、修改并签名
- 《处方管理办法》第八条：试用期人员开具处方，应当经所在医疗机构有处方权的执业医师审核并签名后方有效

**结论**：系统不能"让实习医生独立门诊"，而是加一条审签链。

---

## 2. 角色三档

在 `sys_employee` 加一列 `practitioner_type`（或挂在岗位 `sys_employee_post` 上，因为同一人可能在不同科室身份不同）：

| 码值 | 含义 | 登录后行为 |
|---|---|---|
| 1 | 执业医师 | 现状，结诊即锁定，病历处方自己负责 |
| 2 | 试用期医师 | 能独立接诊，结诊后进"待带教审签"队列 |
| 3 | 实习医生 | **不允许独立登录医生站选患者**，只能在带教老师会话里"代写" |

> 为什么挂岗位而不是员工：一个主治医生在本科室是带教老师，去支援门诊时可能是独立执业者；规培生在不同科室带教老师不同。

## 3. 状态机改造

### 3.1 病历状态 `biz_medical_record.record_status`

现有：`0-草稿 1-已保存 2-已提交/锁定 3-已审核`（病案室事后）。

新增中间态：

```
0 草稿
1 已保存（未结诊）
2 已提交/已锁定（执业医生结诊后；或试用期医生被带教审签后）
3 病案室已审核（事后终末质控，不动）
4 待带教审签（试用期医生点了结诊，等上级签）  ← 新增
5 已退回（带教老师驳回，带意见）              ← 新增
```

状态流转：

```
执业医生：   1 --结诊--> 2（直接锁定）
试用期医生：1 --结诊--> 4 --带教通过--> 2
                        \--带教退回--> 5 --医生改完再结诊--> 4
```

**关键**：状态 4 期间，处方不生效、L2 账单不出、处方 PDF 不生成、患者不能缴费取药。带教审签通过后这一批动作才触发（可以复用我们刚做的 `ClinicSubmittedEvent`，把触发点从"医生点结诊"改成"带教点通过"）。

### 3.2 处方签名 `biz_prescription`

现有签名一行：`doctor_sign_id / doctor_sign_name / doctor_sign_time / doctor_signature`。

试用期/实习医生开的处方要双签，加列：

```sql
review_doctor_id      BIGINT       -- 带教老师员工ID
review_doctor_name   VARCHAR(32)  -- 带教老师姓名
review_signature     TEXT         -- 带教老师手写签名图片
review_signed_time   DATETIME     -- 带教老师审签时间
```

PDF 处方签落款区两行：

```
书写者：张实习（电子签名 · 2026-10-24 14:30，仅作记录）
审签者：李主任（手写笔迹）（电子签名 · 2026-10-24 15:02，可验签）
```

执业医生开的处方 `review_*` 全 null，PDF 只显示一行签名（现状）。

## 4. UI 改动

### 4.1 带教老师工作台

- 顶部候诊队列旁加一个红色徽标 tab："待我审签 (N)"
- 点开是一张表：患者姓名、科室、下级医生、就诊时间、病历完成度（必填项缺几个）、操作【审签】
- 点【审签】弹全屏：左边病历只读、右边处方列表只读，底部两个按钮：
  - 【通过并签名】：要弹手写签名板，签完即落库
  - 【退回修改】：必填退回意见（弹窗 textarea），打回给下级

### 4.2 试用期医生工作台

- 结诊按钮文案不变，但点完后弹 toast："病历已提交，待带教老师审签后方可生效"
- 该患者卡片状态徽章变橙："待带教审签"
- 被退回的患者卡片变红，附退回意见气泡
- 状态 4/5 期间：处方/费用栏只读，不显示"病历已提交"水印，改显示橙色"待审签，暂不能取药"

### 4.3 实习医生账号

- 登录后**不显示候诊队列**，主界面只有"我带教老师的患者"列表
- 必须由带教老师在自己工作站里点【带入实习医生】选这个学生账号，才能在病历编辑框获得临时写权限
- 没有带教老师在场时，实习医生账号点不动任何"接诊/开处方"按钮

## 6. 不做的边界

- **不做**实习医生独立排班、独立挂号：法规不允许
- **不做**带教老师事后补签（必须实时审，补签=篡改）
- **不做**按科室自动分配带教老师：默认取该员工 `sys_employee_post` 里同科室的主治医师及以上，医生手动选
- **不做**批量审签：单张过，每张都要手写签名
