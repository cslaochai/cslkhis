2. `recordForm.diagnosis` 永远空串 —— 结诊强校验 diagnosis，本页只有名称/编码两个输入框（门诊站是 ICD select 一次填三字段），保存必崩「诊断不能为空」。修法：`diagnosis: recordForm.diagnosis || recordForm.diagnosisName`。

### 踩坑（都记下来，下次不踩）
- **`@PreAuthorize` 越权测试必须给合法 body**：`handoverSave` 用 `{deptId, shiftId}` 调，`@Valid` 缺 `takeEmpId`/`items` 在**参数解析阶段**就 400，`@PreAuthorize` 根本没执行——403 测不到不是因为权限失效，是用例短路。改用合法 body + 不存在的 emergencyId（权限若真漏了业务层也会拒，不写库）。
- **权限缓存键名是 role_code 不是 role id**：`his:perm:role:10019`（不是 `:8`）；另有身份缓存 `his:user:identity:{username}`。授权变更后两个键都要 DEL。
- 非 filterable 的 el-select 原生 input 是**隐藏的**，playwright 点 input 必超时——点 `.el-select` 容器。
- el-message 默认 3s 退场，UI 断言「保存成功」要按文本精确匹配，否则被上一步残留 toast 抢判。
