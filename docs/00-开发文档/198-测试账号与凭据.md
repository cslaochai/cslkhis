## 五、按需反查 SQL（角色 → 账号）

> 各角色首个可登录账号已并入第二节「院内 PC 端账号」，此处仅保留反查方法。

自己反查（`role_id` 与 `role_code` 不是一套，别混）：

```sql
-- 2=医生(10013) 3=护士(10014) 4=收费员(10015) 5=药剂师(10016) 7=前台导诊(10018) 9=分诊护士(10020)
SELECT u.user_name, u.real_name, r.role_code, d.dept_name
FROM sys_employee_post p
JOIN sys_user u      ON u.emp_id = p.employee_id
JOIN sys_role r      ON r.id     = p.role_id
LEFT JOIN sys_department d ON d.id = p.dept_id
WHERE p.role_id = 2 AND u.del_flag = 0 AND u.status = 1;
```
