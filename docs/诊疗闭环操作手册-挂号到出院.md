# 长沙麓康医院 HIS —— 诊疗闭环操作手册（挂号 → 出院）

> 用途：照着这份手册，能在浏览器里把"一个患者从挂号到出院"的完整流程跑通。
> 范围：聚焦最常用的**门诊 + 住院核心闭环**及其收尾环节（药房发药、护士执行、医技报告）。
> 其他管理类模块（系统管理、报表、医保、物资、绩效等）见文末「其他模块速查」，不展开。
> 所有按钮、菜单路径、权限码均已对照前端源码（`source/front/src`）核对，不是凭印象。

---

## 0. 上手前必读

### 0.1 登录与角色
- 前端地址：`source/front` 跑起来后访问（dev 默认 3000 端口）。
- 账号口令：见 `docs/测试账号与凭据.md`，默认口令统一 `123456`。
- **本系统是"按角色看菜单"的**：你用哪个角色登录，左侧菜单就只显示那个角色该看的。
  测试时要切对角色——切换角色 = 换身份 + 换落点（不是只换头像）。
- 常用 5 类角色：挂号员、门诊医生、收费员、住院医生/住院处、护士、药师、医技技师。

### 0.2 一条主链的话术
```
门诊线：  挂号 → 签到(可省) → 门诊就诊 → 门诊收费
住院线：  （门诊就诊时开住院证）→ 住院收治 → 住院诊疗 → 出院办理 → 出院结算
收尾环节： 医生开处方/检查 → 药房发药 / 医技出报告 / 护士执行医嘱
```
门诊线走到头就算"看完了"；要"到出院"必须走住院线。住院线是门诊线的下游分支。

## 1. 阶段 0：排班（挂号的前提，漏了挂不上）

| 项 | 内容 |
|---|---|
| 角色 | 排班管理员 / 门诊办主任 |
| 菜单 | **排班**（`/schedule`，门诊出诊计划） |
| 动作 | 给医生排好某天某时段的门诊班 |
| 为什么 | **号源来自排班**。没排班，"预约看板"里那个医生的格子是空的，挂不了号 |
| 下一步 | 去阶段 1 挂号 |

> 若只是想快速验证挂号流程，先在 `/schedule` 给一个医生排一班，再回来挂号。

---

## 2. 阶段 1：门诊挂号（挂号员）

| 项 | 内容 |
|---|---|
| 角色 | 挂号员 |
| 菜单 | **预约/挂号** → 进入"预约看板"（`/appointments`） |
| 主要按钮 | ① 右上角 **「新增预约」**（权限 `opd:appointments:add`）；② 看板里某医生某时段格子上的 **「预约」** 按钮（`desk-cell-add`） |
| 操作 | 选患者 → 选科室/医生/时段 → 确认 |
| 状态变化 | 总挂号数 +1，该患者进入"待就诊 → 已挂号" |
| 下一步 | 去阶段 2 签到（或跳过直接阶段 3 接诊） |

看板顶部 6 张卡片实时显示：总挂号 / 待就诊 / 已签到 / 已完成 / 已退号 / 已过号。
某行出现 **「退号」** 按钮即可退号（仅"已挂号/已签到"状态可见）。

---

## 3. 阶段 2：签到（分诊台，视流程可省）

| 项 | 内容 |
|---|---|
| 角色 | 分诊台护士 |
| 菜单 | **分诊台**（`/triage`） |
| 动作 | 把"已挂号"的患者点成"已签到" |
| 说明 | 若你们流程不分诊、医生直接看，医生站「接诊」会自动推进，此步可跳过 |
| 下一步 | 阶段 3 门诊就诊 |

---

## 4. 阶段 3：门诊就诊（门诊医生）

| 项 | 内容 |
|---|---|
| 角色 | 门诊医生 |
| 菜单 | **门诊医生工作站**（`/doctor-workstation`） |
| 第一步 | 用页面上的患者选择器（`PatientSelect`）选患者 → **接诊** |
| 核心动作 | ① 写门诊病历（主诉 / 现病史 / 诊断）；② 开医嘱 / 处方（药品、检查、检验）；③ **若要办住院：在此开「住院证」** |
| 状态变化 | 患者"待就诊 → 已完成（就诊）" |
| 下一步 | 开处方/检查后 → 阶段 4 收费；若开了住院证 → 阶段 5 住院收治 |

> **住院证是门诊 → 住院唯一的桥**：在医生站开证后，`/inpatient` 顶部的"待收治（住院证）"列表会立刻多出一条记录。不开证，住院侧收治无从点起。

---

## 5. 阶段 4：门诊收费（收费员）

| 项 | 内容 |
|---|---|
| 角色 | 收费员 |
| 菜单 | **门诊收费**（`/cashier`） |
| 动作 | 选患者 / 挂号号 → 收挂号费、处方费、检查费 → 确认支付 |
| 说明 | 收费四层台账在 `/fee-record`、`/settlement-bill`、`/payment-txn`、`/fund-account`，但出账收款主战场就是 `/cashier` |
| 下一步 | 仅门诊：流程结束。转住院：回阶段 3 开住院证后走阶段 5 |

---

## 6. 阶段 5：住院收治（住院处 / 床位中心）

> 二选一，A 是顺路做法。

### A. 住院证一键收治（推荐）
| 项 | 内容 |
|---|---|
| 菜单 | **在院管理**（`/inpatient`） |
| 动作 | 顶部 **「待收治（住院证）」** 区 → 选刚开的证 → **收治**（分配科室 + 床位） |
| 状态变化 | 患者进入"在院"，床位占用 |

### B. 床位中心排队收治
| 项 | 内容 |
|---|---|
| 菜单 | **床位管理**（`/bed-center`） |
| 动作 | **「登记排队」**（`ipd:bedCenter:add`）→ 在等床队列里 **安排床位** → 收治 |
| 状态变化 | 等待中 → 已安排床位 → 已收治入院 |

> 也可走 `InpatientView` 顶部 **「入院登记」** 按钮（`ipd:inpatient:add`）直接入院，但无住院证时需手动选患者来源。

---

## 7. 阶段 6：住院诊疗（住院医生 / 护士）

| 模块 | 菜单 | 动作 |
|---|---|---|
| 住院医嘱 | **住院医嘱**（`/inpatient-order`） | 开长期 / 临时医嘱（药品、治疗） |
| 住院病历 | **住院病历**（`/inpatient-record`） | 写入院记录 / 病程记录 |
| 护士执行 | **护士工作站**（`/nurse`） | 「医嘱执行」页签，执行 / 校对医生开的医嘱 |
| 检验检查 | 各医技工作站（见阶段 9） | 登记 → 采样 → 出报告 |

---

## 8. 阶段 7：出院办理（住院医生 / 住院处）

| 项 | 内容 |
|---|---|
| 菜单 | **在院管理**（`/inpatient`） |
| 动作 | 在院患者列表行内 **「出院」** 按钮 → 弹 **「出院办理」** 框 → 填出院时间 / 出院医生 / 出院诊断编码+诊断 / 出院小结 → 点 **「确认出院」** |
| 效果 | 床位释放、入院状态置"已出院"、病案首页回写住院天数与离院方式 |
| 下一步 | 阶段 8 出院结算 |

> ⚠️ **出院办理在「在院管理」页，不在「住院结算」页**。结算是出院后的费用清算，两个独立动作。

---

## 9. 阶段 8：出院结算（收费员 / 住院结算）

| 项 | 内容 |
|---|---|
| 菜单 | **住院结算**（`/inpatient-settlement`） |
| 动作 | 选患者 → 汇总住院费用、医保、自付 → 确认结算 |
| 说明 | 这是费用清算；若在院期间已交预交金，此处冲抵 |
| 到此 | 一个患者从挂号到出院全流程结束 |

## 10. 闭环里的收尾环节（开单后必须有人收尾，否则流程不闭合）

### 10.1 药房发药（药师）
| 项 | 内容 |
|---|---|
| 菜单 | **药房窗口**（`/pharmacy-window`） |
| 动作 | 待发药列表 → 每行 **「发药」** 或 **「整单发药」** → 弹「发药复核」框（麻精药品需双人复核、复核人不得与发药人同一人）→ **「确认发药」/「确认整单发药」** |
| 状态 | 待发药(1) → 已发药(2)（退药为 3） |

### 10.2 护士执行医嘱（护士）
| 项 | 内容 |
|---|---|
| 菜单 | **护士工作站**（`/nurse`） |
| 动作 | 「医嘱执行」页签，对医生开的医嘱执行 / 校对（皮试、输液等在此落地） |

### 10.3 检验出报告（医技技师）
| 项 | 内容 |
|---|---|
| 菜单 | **检验工作站**（`/laboratory-workstation`，即 `lab/LaboratoryView`） |
| 流转 | 已登记 → 已采样 → 已接收 → 检验中 → 已出结果 → **「审核」**（确认审核通过）→ 已发布(7) |
| 动作 | 列表行 **「审核」** → 审核对话框填意见 → **「确认审核通过」** |

> 检查（放射/超声/心电/病理/内镜）各有独立工作站，逻辑类似：登记 → 出报告 → 审核 → 发布。

## 11. 一踩就坑的点（必看）

1. **「患者请假离院」(`/inpatient-leave`) ≠ 出院**。那是请假，床位不释放、状态不变。真出院只在 `/inpatient` 的「出院」按钮。
2. **出院办理在「在院管理」页，不在「住院结算」页**。
3. **挂号依赖排班号源**：阶段 0 不做，阶段 1 挂空。
4. **住院证是门诊 → 住院唯一的桥**：不开证，住院侧"待收治"列表永远空。
5. **切换角色 = 换身份 + 换落点**：每个按钮都带 `v-perm` 权限码，用错角色要么看不到按钮、要么被 403 踢。
6. **处方开了 ≠ 药发了**：开完处方还要去 `/pharmacy-window` 发药，否则药房库存不扣、患者拿不到药。
7. **检查/检验开了 ≠ 出报告了**：开了申请还要去对应医技工作站登记、出报告、审核、发布，临床才能在病历里看到结果。

## 12. 验收自检清单（每阶段做完应看到什么）

- [ ] 排班：目标医生在某天某时段有排班记录
- [ ] 挂号：预约看板"总挂号" +1，患者出现为"已挂号"
- [ ] 就诊：医生站该患者有门诊病历 + 至少一条医嘱/处方
- [ ] 收费：该患者费用已收费（现金/账户变动可见）
- [ ] 住院证（如转住院）：`/inpatient` 顶部"待收治"出现该证
- [ ] 收治：患者状态"在院"，床位占用数 +1
- [ ] 医嘱/病历：住院医嘱、住院病历有内容；护士站待执行医嘱可勾执行
- [ ] 发药（如开药）：药房窗口该处方"已发药"
- [ ] 报告（如开检查）：医技工作站该申请"已发布"
- [ ] 出院办理：`/inpatient` 该患者状态"已出院"，床位释放（占用 -1）
- [ ] 出院结算：住院结算该患者有结算记录
